1. SYSTEM ARCHITECTURE OVERVIEW
================================================================================
The platform stores domestic flight price observations collected across airlines
(IndiGo, Air India, Air India Express, Akasa Air, SpiceJet) and OTAs (MakeMyTrip,
EaseMyTrip) to compute the official real-time Consumer Price Index (CPI) airfare
sub-component for the Ministry of Statistics and Programme Implementation (MoSPI).

Relationship Model:
  [routes] ------------< [dgca_route_weights]
     |
     +-----------------< [price_quotes] >----------------- [airlines]
                                |                                |
                                |                                v
                    [airfare_index_records]            [scraper_audit_logs]

Scraper developers only write to two tables:
  1. price_quotes (for extracted fare observations)
  2. scraper_audit_logs (for crawler health, latency, proxy, and status)

The remaining tables (routes, dgca_route_weights, airlines) are pre-seeded
and read-only for scrapers. Table airfare_index_records is generated by the
downstream statistical math engine.

3. DATA INSERTION GUIDE FOR SCRAPERS
================================================================================

When writing Playwright, Selenium, or Scrapy crawlers:
1. Extract flight quotes into a standard Python list of dictionaries.
2. Call the built-in batch ingestion function:
      from backend.ingestion import ingest_scraper_batch

The ingestion utility automatically:
  - Looks up route_id from route_code (e.g. "DEL-BOM")
  - Looks up airline_id from airline_code (e.g. "6E")
  - Automatically computes base_fare and taxes_and_fees if only total_fare is given
  - Computes SHA-256 hash of raw HTML/JSON response for Government Proof-of-Source
  - Saves raw HTML snapshot into data/snapshots/
  - Writes all quotes into price_quotes
  - Writes crawler status and latency into scraper_audit_logs
  - Performs the entire operation inside a single atomic database transaction!

COMPLETE PYTHON SCRAPER INGESTION EXAMPLE
--------------------------------------------------------------------------------

```python
import time
from backend.ingestion import ingest_scraper_batch

# Step 1: Scraper visits airline portal and extracts flight quotes
start_time = time.time()

# Mock extracted data from IndiGo for DEL -> BOM on T+7 window:
extracted_flights = [
    {
        "flight_number": "6E-204",
        "flight_date": "2026-09-12",
        "advance_window": "T+7",          # "T+1", "T+7", "T+15", "T+30", "T+45"
        "departure_time": "07:15",
        "arrival_time": "09:30",
        "duration_mins": 135,
        "stops": 0,                       # 0 = Direct, 1 = 1-stop
        "total_fare": 7650.0,             # Total price seen by user (INR)
        "base_fare": 6200.0,              # Optional: base fare before tax
        "taxes_and_fees": 1450.0,         # Optional: calculated automatically if omitted
        "cabin_class": "Economy",         # "Economy"
        "fare_type": "Standard",          # "Saver", "Standard", "Flexi"
        "seats_remaining": 4,             # Scarcity indicator (optional)
        "source_url": "https://www.goindigo.in/search?from=DEL&to=BOM&date=2026-09-12"
    },
    {
        "flight_number": "6E-545",
        "flight_date": "2026-09-12",
        "advance_window": "T+7",
        "departure_time": "14:00",
        "arrival_time": "16:05",
        "duration_mins": 125,
        "stops": 0,
        "total_fare": 8410.0
    }
]

raw_html_payload = "<html>... airline search result page ...</html>"
latency = int((time.time() - start_time) * 1000)

# Step 2: Ingest into database
upload_result = ingest_scraper_batch(
    route_code="DEL-BOM",                 # Monitored route code
    airline_code="6E",                    # 6E, AI, IX, QP, SG, MMT, EMT
    quotes=extracted_flights,
    crawler_status="SUCCESS",             # SUCCESS, CAPTCHA_BYPASSED, BLOCKED, etc.
    http_status=200,
    latency_ms=latency,
    proxy_ip="103.25.44.12",              # Proxy IP used (optional)
    raw_payload=raw_html_payload          # Raw response for government audit hash
)

print("Ingestion Result:", upload_result)
# Output:
# {
#   'status': 'SUCCESS',
#   'route_code': 'DEL-BOM',
#   'airline_code': '6E',
#   'quotes_saved': 2,
#   'snapshot_hash': 'bc7c8fc96a25bf6ff...',
#   'timestamp': '2026-09-05T01:30:00+00:00'
# }
```

================================================================================
4. PROOF OF SOURCE & GOVERNMENT AUDITABILITY
================================================================================
MoSPI evaluators require all scraped price data to be fully auditable.
The platform achieves this through:
1. snapshot_hash: SHA-256 cryptographic hash calculated from the raw HTML payload.
2. snapshot_path: Raw response saved on disk in `data/snapshots/`.
3. Evaluators can click any price point on the dashboard and view the exact
   timestamped snapshot and raw response verifying that the fare quote was authentic.
